OTA：下载完成与“可稳定使用”分别确认

  1. 下载完整B稳定A保留，B成为PENDING；main和Async都校验。
  2. 真实打开B取页面lease后才TRIAL，候选坏或缺目标继续稳定A。
  3. 确认健康SDK实际首屏与JS业务healthy齐全，核来源、身份和最新决定后提交。
  4. 失败或重启清旧TRIAL；恢复稳定版本，退休失败导航来源，保留仍活着的旧页面lease。

候选模式默认关闭。启用方式沿宿主配置；Demo可用既有Want参数lynx_ota_candidate_mode=1。正式业务仍使用已有App版本范围投放Bundle，本轮没有新增协议版本门槛或签名机制。

本地缓存读取不等待整批网络同步。流式下载对象总量20MiB、Async清单不超过其声明大小（上限1MiB）、实际待写512KiB，超限明确失败；并不宣称系统HTTP有暂停/背压机制。

真实差异：不能把软件遗漏说成硬件限制

系统API能力
  • Harmony系统CameraPicker无法关闭录像音轨；false明确UNSUPPORTED，相册及预览不受影响。
  • 外部Browser不是本Module拥有，无法保证close；本地文档没有handler时明确NO_HANDLER。
  • 系统分享/权限界面由系统管理，owner取消保证Bridge终态，不保证系统面板由App强制销毁。
实际硬件与Provider
  • 相机方向、麦克风、传感器及生物认证凭据需设备实际具备；明确不可用，不伪造FaceID。
  • Push厂商服务、后台JS runner、SQLCipher在现有两端也未配置，保持真实Provider边界，不初始化商业SDK。
  • 地图按你的最新决定延期。高级转场本次包含，已完成源码实施与有界独立复核。
业务需要注意的行为变化
  • SharedElement快照代理通过矩形洞移除原元素；洞底目前使用承载层常量背景，内部父容器的渐变或图片底纹不能从原截图恢复。这是已知视觉表达差异，不能按硬件豁免，也不能称全场景像素一致。
  • API13没有KeyboardAvoidMode.NONE：nothing/none显式拒绝，不静默按OFFSET成功。API14及以上可用。
  • NativeTab不在两端既有Lynx Page结果栈；Tab打开的第一Page不能凭closeWithResult向Tab消费结果，可用既有session/message机制，不能宣称结果API覆盖Tab。
  • Material弧线与Sheet默认值在双端原源码本就有平台差别；Harmony按当前公共合同和明确默认归一化，不保证控制点数值或系统材质逐像素相同。
  • Filesystem省略directory现在与两端一致为CACHE，encoding为UTF8。此前Harmony默认DATA的历史相对路径不会自动迁移，业务有旧文件时应显式指定DATA。
  • Device不能可靠判断虚拟设备时返回isVirtual:null / isVirtualKnown:false。
  • 媒体返回平台真实字段，Harmony新选择为results；模板已接消费，未产生新的编译Bundle。
  • 原生选择后保留的成功缓存沿系统cache生命周期；不能据20MiB单文件预算宣称磁盘缓存永不增长。
